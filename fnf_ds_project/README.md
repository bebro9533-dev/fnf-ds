# FNF DS lite

Лёгкая версия FNF для Nintendo DS. Управление стилусом по нижнему экрану (4 дорожки).

## Сборка без установки (GitHub)
1. Создай репозиторий на github.com и залей в него содержимое этой папки (включая .github).
2. Открой вкладку Actions, дождись сборки "Build NDS".
3. Внутри завершённого запуска в Artifacts скачай fnf_ds, внутри лежит fnf_ds.nds.
4. Открой .nds в melonDS или DeSmuME.

## Сборка локально
Установи devkitPro (devkitARM + libnds), открой терминал devkitPro в этой папке и выполни `make`.
